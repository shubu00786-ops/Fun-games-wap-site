# 🎮 Fun Games WAP Site

A collection of fun web-based arcade games built with HTML, CSS, and JavaScript.

## Games Available

### 🎯 Shubu Arcade
A simple but addictive clicker/tapper game where you tap a golden button to increase your score!

**Features:**
- ✨ Score tracking with localStorage (score persists even after page refresh)
- 🎨 Modern dark theme with golden button
- 📱 Mobile responsive design
- 🔄 Reset button to start over
- ⚡ Smooth animations and hover effects

**How to Play:**
1. Click/tap the golden TAP button as fast as you can
2. Each tap increases your score by 1
3. Your score is automatically saved
4. Click Reset to start fresh

**Play Online:** [Shubu Arcade](./arcade/index.html)
